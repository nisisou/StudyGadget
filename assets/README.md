# Study Companion (Android)

キャラクター版の導入・背面法・AI連携・モデル更新は、プロジェクトルートの `README.md` を参照してください。

Nintendo 3DS (自作Homebrew「Study Gadget」) と同一Wi-Fi内で通信し、学習記録の受信・保存・可視化・メディア操作を行うAndroidアプリケーションです。

---

## 1. ビルド手順

### 必須環境
- Android Studio Ladybug (2024.2.1+) または同等のGradle環境
- JDK 17 以上 (JDK 21 / 25 推奨)
- Android SDK 35 (minSdk 26)

### ビルド & テスト実行コマンド
```bash
# プロジェクトのビルド (Debug APK生成)
./gradlew assembleDebug

# 単体テストの実行
./gradlew test
```

---

## 2. 3DSとの接続手順 (ペアリング手順)

1. **アプリの設定画面を開く**
   - 設定タブの「ペアリング設定」を確認します。
2. **トークンと接続先情報の確認**
   - 表示されている「認証トークン」(32文字の英数字) または「config.txt1行コピー」ボタンを押して情報をコピーします。
3. **3DS側の設定**
   - 3DS SDカード内の Study Gadget 設定ファイル (`config.txt`) に以下を記述します:
     ```text
     <スマホのIP> <ポート番号> <トークン>
     ```
     例: `192.168.1.100 8765 AbCdEf1234567890abcdef1234567890`
   - あるいはQRコード読み取りに対応したクライアントの場合は設定画面のQRコードを表示してスキャンします。
4. **同期テスト**
   - スマホのホーム画面で「サーバー稼働中」になっていることを確認し、3DS側からタイマーを開始/終了します。

## 3. 機能・制約事項

### §7 メディア操作の制約
- `AudioManager` 経由でシステムメディアキーイベント (`PLAY_PAUSE`, `NEXT`, `PREVIOUS`, `VOLUME_UP`, `VOLUME_DOWN`) を送信します。
- ターゲットの音楽再生アプリ (Spotify, YouTube Music, Apple Music 等) のバックグラウンド再生仕様や権限状態により、操作への応答が端末ごとに異なる場合があります。設定画面およびメディア画面にテスト送信ボタンを配置しています。

### §9 Studyplus 連携の制約
- Studyplus公式APIが一般公開されていない前提のため、インターフェース準拠のスタブ (`StudyplusSink`) として実装されています。
- 設定画面で有効化フラグを切り替え可能です。
- 代替機能として CSV 書き出し (`ACTION_SEND` 共有および `/api/export.csv` エンドポイント) を提供しています。
- 画面スクレイピングや Accessibility Service による自動操作はPlayポリシー遵守のため実装していません。

## 4. 仮定した点

1. **ネットワークインターフェース**:
   - 複数IPが存在する場合 (Wi-Fi, テザリング/ホットスポット)、全てのプライベートIPv4アドレスを列挙して通知および設定画面に表示します。
2. **Liveセッションの自動クリア**:
   - 12時間 (43,200秒) 以上更新がないLiveセッションは自動的に無効化・クリアされます。
3. **重複セッション (冪等性)**:
   - 同一 `id` (開始UNIX秒) のセッションが再送された場合、Room DBの `OnConflictStrategy.IGNORE` により既存レコードを保持し、HTTP 200 `{"ok":true}` を返します。
4. **科目コードの切り詰め**:
   - `/api/config` 生成時、3DS画面幅とバッファ制限(4KB)のため、各科目のラベルはUTF-8で最大24バイトに切詰処理します。
